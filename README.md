One original dad joke, written to be told out loud at the dinner table:

> I tried to teach my dog to fetch the newspaper, but he keeps bringing me the same old news.

## Run it

```sh
node main.ts
```

`main.ts` validates the joke against the entry gate (one sentence, 1–200 UTF-8 characters, single line, punchline in the final clause) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
